# Códigos do Projeto

Pasta contendo os códigos utilizados no desenvolvimento do jogo Fangs and Fists.

## Arquivos

- `nfc-botao.py` - Comunicação entre Python e Arduino e controle das ações do jogo.
- `sketch-nfc-botao.ino` - Leitura dos botões e das tags RFID utilizando o Arduino e o módulo MFRC522.
