# 🎮 Fangs and Fists

### Códigos-fonte do projeto

Projeto desenvolvido utilizando **mBlock**, **Arduino** e **Python** para integração entre hardware e software em um jogo interativo.

</div>

---

## 📂 Arquivos do Projeto

<div align="center">

| Arquivo | Descrição |
|----------|----------|
| 🐍 `leitor_rfid.py` | Comunicação entre Python e Arduino, leitura de tags RFID e controle das ações do jogo |
| 🔌 `leitor_rfid.ino` | Código do Arduino responsável pela leitura dos botões e das tags RFID |
| 🎨 `FangsAndFists.mblock` | Projeto principal desenvolvido no mBlock |

</div>
